# Data

The processed CSV files in this directory are local snapshots of the public datasets used by the original IBM Applied Data Science Capstone notebooks.

- `processed/dataset_part_1.csv`: cleaned Falcon 9 launch records.
- `processed/dataset_part_2.csv`: launch records with the binary landing outcome `Class`.
- `processed/dataset_part_3.csv`: one-hot encoded feature matrix for machine learning.

These files are included so the final summary notebook and report can be reviewed without re-downloading remote data.
